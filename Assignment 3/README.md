# Inventory Management System

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features
- Add Product
- Get All Products
- Get Product by ID

- Update Product
- Delete Product
- Filtering and Sorting
- Pagination
- Low Stock Report
- Category-wise Summary
- Schema Validation
- Error Handling

## Run Project
npm install
node server.js

## API URL
http://localhost:5000/api/products
